# N-Tier Architecture

📅 4 Temmuz 2026 | ✍️ Yazar: Ahmet

N-Tier Architecure Nedir?

1. Presentation Layer (Sunum / UI Katmanı)

  • 📌 Nedir: Kullanıcının siteyle veya uygulamayla doğrudan etkileşime girdiği en dış katmandır.
  • ⚙️ Ne Yapar: Gelen istekleri (HTTP Request) karşılar, backend'den gelen verileri kullanıcıya gösterir.
  • 💻 Örnek: ASP.NET Core MVC (Controller ve View yapıları), Web API (Controller'lar) veya Angular/React gibi ön yüz projeleri bu katmanda yer alır.

2. Business Logic Layer (BLL / İş Mantığı Katmanı)

  • 📌 Nedir: Uygulamanın "beyni" olan, tüm kuralların ve mantıksal hesaplamaların döndüğü katmandır.
  • ⚙️ Ne Yapar: Sunum katmanından gelen verileri kontrol eder (Validation), iş kurallarını uygular ve her şey yolundaysa veri katmanına gönderir.
  • 💻 Örnek: "Eğer kullanıcının yaşı 18'den küçükse kayıt etme" veya "Stokta ürün kalmadıysa siparişi iptal et" gibi operasyonlar tamamen bu katmandaki servislerde (Manager sınıflarında) yazılır.

3. Data Access Layer (DAL / Veri Erişim Katmanı)

  • 📌 Nedir: Veri tabanı (Database) ile doğrudan konuşan, veri alıp verme işlerine bakan katmandır.
  • ⚙️ Ne Yapar: Veri tabanına bağlanır; veri ekleme (Insert), silme (Delete), güncelleme (Update) ve listeleme (Select) işlemlerini yürütür.
  • 💻 Örnek: Entity Framework Core, Dapper, Repository Pattern ve Unit of Work yapıları ile DbContext sınıfları tamamen bu katmanda yaşar.

4. Core / Entities Layer (Çekirdek Katman)

  • 📌 Nedir: Projedeki diğer tüm katmanların ortaklaşa kullandığı, uygulamanın veri modellerini (nesnelerini) barındıran merkez katmandır.
  • ⚙️ Ne Yapar: Veri tabanındaki tabloların kod tarafındaki karşılıkları olan sınıfları (Entity) ve ortak yardımcı araçları (Core Utilities) tutar. Diğer katmanlar bu katmanı referans alır.
  • 💻 Örnek: Product, User, Category gibi düz C# sınıfları bu katmanda yer alır.

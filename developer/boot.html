# Windows Boot Manager (BCD) Analizi

Ön yükleme (Boot) mekanizmaları, BCD bozulmaları ve düşük seviyeli sistem kurtarma operasyonları.

0xc000000f: Boot Sektörünün Çöküşü

Bilgisayarın güç tuşuna bastığınız an başlayan o sessiz senfoni, BIOS/UEFI'nin donanımı test etmesi (POST) ve ardından kontrolü diskteki ilk sektörlere devretmesiyle devam eder. Ancak ekranda aniden beliren o meşhur mavi veya siyah arka planlı "Windows Boot Manager" hatası, bu senfoninin en kritik yerinde koptuğunun siber kanıtıdır.

Bu hata genellikle Windows'un hangi disk bölümünden, hangi çekirdek (kernel) parametreleriyle başlatılacağını söyleyen Boot Configuration Data (BCD) veritabanının bozulması, silinmesi veya diske atılan hatalı bir formatlama/bölümleme işlemi yüzünden meydana gelir.

🛠️ Düşük Seviyeli Çözüm Yolları (Terminal Operasyonları)

Sistemi kurtarmak ve Boot sektörü komut satırından yeniden inşa etmek için Windows kurtarma ortamı (RE) üzerinden şu terminal komutlarıyla BCD kayıtlarını ayağa kaldırıriz: 

bootrec /fixmbr      # Ana ön yükleme kaydını (MBR) onarır
bootrec /fixboot     # Yeni bir boot sektörü yazar
bootrec /scanos      # Uyumlu işletim sistemlerini tarar
bootrec /rebuildbcd  # BCD veri tabanını sıfırdan inşa eder

Eğer sistem modern bir UEFI/GPT mimarisiyse, EFI bölümünü manuel olarak mount edip içindeki EFI\Microsoft\Boot\ klasörüne girerek bcdboot komutuyla temiz bir boot yapısı enjekte etmek gerekir.

🔍 Geliştirici Notu: Kendi işletim sistemimizin bootloader'ını (kesme 13h veya GRUB entegrasyonu) yazarken de mantık aynıdır. Bilgisayar, diskin ilk 512 baytındaki 0xAA55 imzasını arar. Eğer o sektör bozuksa veya imza yoksa, donanım işletim sistemini asla tetikleyemez.
